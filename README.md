# Dummy project

Dummy project is Dacs introduction to PCL


## Programming Language

Java 24, 25

## Overview

This project analyzes and categorizes the Maastricht Event Calendar.
It is part of the DACS course and serves as an introduction to PCL (Project centered learning).
The goal is to extract meaningful insights from event data using.

## Goal

* Load and parse the Maastricht event dataset

* Categorize events by type (sport, music, cultural, etc.)

* Analyze temporal patterns (months, seasons, exam periods)

* Produce summaries, statistics, and visual charts
